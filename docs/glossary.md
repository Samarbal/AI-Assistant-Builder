# Glossary

| Term | Meaning |
| --- | --- |
| AI Assistant Builder | The platform for creating, configuring, grounding, testing, publishing, and embedding specialized AI assistants. |
| AI assistant | A specialized AI assistant created and configured through the platform. |
| Knowledge | Information users provide to ground an assistant. |
| Grounding | Using the user's provided knowledge to inform an assistant's responses. |
| Testing | Trying an assistant before publishing it. |
| Publishing | Making an assistant available for use. |
| Embedding | Adding an assistant to an external website. |
