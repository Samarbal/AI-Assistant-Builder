# Intent interview
1. Read AGENTS.md and docs/glossary.md for project vocabulary.
2. Ask one question at a time. Stop after 8 questions.
3. Write intent/<slug>.md from intent/_template.md, in the author's own words.
4. End with "Open questions" and "Status: draft". Never mark it approved.
